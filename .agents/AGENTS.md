# Workspace Rules for FinPulse AI

## 🚨 MANDATORY GIT WORKFLOW RULE: ALWAYS USE PULL REQUESTS (PR)
- **NEVER** push code directly to the `master` or `main` branch.
- **ALWAYS** create a dedicated feature branch for any task, feature, or bug fix (e.g. `feature/pwa-manifest`, `feature/fca-rss-sync`).
- **ALWAYS** commit and push the feature branch to GitHub (`git push origin feature/...`).
- **ALWAYS** open a GitHub Pull Request using `gh pr create` with a clear title, description, and issue reference before requesting review or merging!
